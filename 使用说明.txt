喵伴 MiaoBan 2.0 · 使用说明
====================================

一、怎么开始
  1. 把 MiaoBan.exe 放到一个文件夹里（建议单独建一个，比如 D:\MiaoBan）。
  2. 双击 MiaoBan.exe。
  3. 小猫出现在屏幕右下角，坐在任务栏上。

二、它会做什么
  · 你打字 / 动键鼠时，它会踩奶、敲键盘；
  · 打得太快，它会变红、头顶冒蒸汽（过热）；
  · 鼠标快速划过，它会压低身子去追你的光标；
  · 90 秒不碰电脑，它趴下睡觉，头顶冒 z；
  · 单击它：眯眼笑 + 爱心 + "喵~"；
  · 它的眼睛会跟着鼠标转；
  · 右键它：摸摸头 / 专注 25 分钟 / 起来动一动 / 去追鼠标 / 大小 / 总在最前 /
    喝水提醒 / 久坐提醒 / 开机自动出现 / 关于 / 退出。

三、常用操作
  · 拖动：按住小猫拖到任意位置，松手会像麻薯一样晃两下。
  · 大小：右键 → 大小 → 小 / 中 / 大。
  · 番茄钟：右键 → 开始专注 25 分钟，猫头顶会浮一个计时器。
  · 开机自启：右键 → 开机自动出现（写在当前用户注册表 Run 项，不动系统目录）。
  · 退出：右键小猫 → 退出；或右下角托盘图标右键 → 退出。

四、第一次运行被 Windows 拦
  如果出现"Windows 已保护你的电脑"：
    点"更多信息" → "仍要运行"。
  原因：这个 exe 没有购买代码签名证书（一张证书一年几千元），不是病毒。
  从微信/网盘下载的，可以先右键 exe → 属性 → 勾选"解除锁定" → 确定。

五、常见问题
  Q：需要安装吗？占多少空间？
  A：不用安装，单个 exe 约 97KB。不联网、不上传任何数据。

  Q：杀毒软件提示怎么办？
  A：因为没有签名证书，属于常见误报。软件不联网、不读你的文件；
     不放心可以自己上传 https://www.virustotal.com 扫一遍。

  Q：它怎么知道我打字？
  A：用一个键盘钩子监听按键，只统计"有没有按键"，不记录内容、不保存、不上传。
     如果系统限制了钩子（某些安全软件会拦），它会退化成"检测到你在用电脑就踩奶"。

  Q：支持 Win7 吗？
  A：只在 Win10 / Win11 上实测通过，Win7 未测试。

  Q：配置文件在哪？
  A：%APPDATA%\MiaoBan\config.ini，删掉即恢复默认。

  Q：可以换一只别的猫吗？
  A：可以，需要源码版联系卖家，改形象后重新编译即可。
